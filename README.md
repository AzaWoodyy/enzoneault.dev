# enzoneault.dev

Source of the enzoneault.dev website — Next.js (App Router), Tailwind CSS, Bun, Node 26.

## Setup

```bash
bun install
```

## Develop

```bash
bun dev
```

## Check

```bash
bun run lint       # oxlint + vendored anti-slop rules (tools/oxlint/anti-slop)
bun run typecheck
bun run build
```
